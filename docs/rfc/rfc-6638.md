# RFC 6638 — CalDAV scheduling

Source: [RFC 6638](https://www.rfc-editor.org/rfc/rfc6638.html). **Implemented today: No, for every row.** [Status legend](README.md). CalDAV scheduling transport remains deferred even though iTIP/iMIP scheduling is in scope. This table lists relevant capabilities, not every XML element.

| Property or feature | Purpose | First-release plan | Notes |
| --- | --- | --- | --- |
| CALDAV:schedule-inbox-URL | Incoming scheduling location | No — deferred | Host iMIP ingress is separate |
| CALDAV:schedule-outbox-URL | Outgoing scheduling location | No — deferred | Transactional application outbox is not this protocol resource |
| CALDAV:calendar-user-address-set | Principal calendar addresses | No — deferred | Host address mapping is still required |
| CALDAV:schedule-calendar-transp | Availability participation | No — deferred | Native availability-contribution links are separate |
| CALDAV:schedule-default-calendar-URL | Default scheduling destination | No — deferred | Native routing policy is separate |
| Automatic scheduling | DAV resource side effects | No — deferred | Native scheduling transitions remain in scope |
| Scheduling POST | DAV scheduling transport | No — deferred | No CalDAV outbox endpoint |
| Schedule-Tag | Scheduling validator | No — deferred | Feed ETag/application revision are distinct |
| If-Schedule-Tag-Match | Scheduling precondition | No — deferred | No DAV scheduling-tag contract |
| SCHEDULE-AGENT parameter | Scheduling handler | No — deferred | Not automatically enabled by iTIP |
| SCHEDULE-STATUS parameter | Delivery outcome | No — deferred | Native delivery state is separate |
| SCHEDULE-FORCE-SEND parameter | Forced scheduling send | No — deferred | No DAV auto-scheduling behavior |
| CalDAV scheduling privileges | DAV authorization | No — deferred | Host authorization adapters still required |

See [RFC 5546](rfc-5546.md), [RFC 6047](rfc-6047.md) and [standards](../standards.md). The distinction prevents confusing email scheduling and native workflow with a CalDAV scheduling server.
