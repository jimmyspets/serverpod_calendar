# RFC 4791 — CalDAV

Source: [RFC 4791](https://www.rfc-editor.org/rfc/rfc4791.html), sections 4–9. **Implemented today: No, for every row.** [Status legend](README.md). CalDAV remains deferred; the rows identify relevant protocol capabilities we are not promising. This is not a full inventory of WebDAV/XML dependencies.

| Property, report or feature | Purpose | First-release plan | Notes |
| --- | --- | --- | --- |
| Calendar collection | CalDAV storage resource | No — deferred | Native calendars do not imply WebDAV collections |
| MKCALENDAR | Create collection | No — deferred | Native CRUD is separate |
| CALDAV:calendar-description | Collection description | No — deferred | RFC 7986 metadata does not implement this XML property |
| CALDAV:calendar-timezone | Collection zone | No — deferred | Native zone handling is separate |
| CALDAV:supported-calendar-component-set | Component discovery | No — deferred | No CalDAV discovery contract |
| CALDAV:supported-calendar-data | Format discovery | No — deferred | Native/interchange profile documented separately |
| CALDAV:max-resource-size | Size capability | No — deferred | Native limits still required |
| CALDAV:min-date-time | Earliest supported date | No — deferred | Not a native API property by implication |
| CALDAV:max-date-time | Latest supported date | No — deferred | Same boundary |
| CALDAV:max-instances | Recurrence limit | No — deferred | Native work budgets still required |
| CALDAV:max-attendees-per-instance | Attendee limit | No — deferred | Native/mail limits still required |
| CALDAV:calendar-home-set | Collection location | No — deferred | No principal discovery service |
| CALDAV:calendar-query REPORT | Search calendar objects | No — deferred | Native query is separate |
| CALDAV:calendar-multiget REPORT | Fetch object set | No — deferred | Native generated-client calls are separate |
| CALDAV:free-busy-query REPORT | CalDAV availability | No — deferred | Native free/busy and iTIP exchanges remain in scope |
| WebDAV resource methods | Remote object editing | No — deferred | Not the read-only feed route |

See [standards scope](../standards.md). Supporting iCalendar, ETags or native list-based availability does not constitute CalDAV support.
