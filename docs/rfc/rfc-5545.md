# RFC 5545 — iCalendar

Source: [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545.html), especially sections 3.2–3.8 and 8.3. **Implemented today: No, for every row.** First-release plans below follow existing requirements and proposed ADRs; they are not accepted conformance claims. See the [status legend](README.md) and [native/feed boundary](../compatibility.md).

## Recurrence and temporal forms

[ADR 0029](../adr/0029-date-recurrence-rule-values.md) implements native DATE-only parameter range/combination validation and maintainer-confirmed sorted, duplicate-free native filter lists. [ADR 0030](../adr/0030-bounded-date-recurrence-generation.md) adds an initial bounded DATE-only generator with explicit mismatch/limit errors; [ADR 0031](../adr/0031-date-recurrence-week-numbers.md) adds native DATE-only yearly BYWEEKNO with all WKST values and scoped week-year evidence. [ADR 0033](../adr/0033-date-recurrence-sets.md) adds bounded native DATE-only union/subtraction. [ADR 0036](../adr/0036-date-event-series-overlap.md) adds scoped native uniform-length DATE-only span overlap queries, separate from wire support. [ADR 0037](../adr/0037-date-only-single-occurrence-exceptions.md) adds native single-occurrence DATE exceptions with bounded effective-set target validation and moved/changed-length overlap queries. [ADR 0038](../adr/0038-date-only-this-and-future-timing.md) adds scoped native DATE-only THISANDFUTURE timing and bounded overlap queries. Full timed/PERIOD sets, range cancellation/task exceptions and wire parsing/export remain pending; the selected full recurrence features below remain planned. Native ISO display fields under [ADR 0034](../adr/0034-native-iso-week-fields.md) are separate from rule-specific WKST membership and do not add a protocol feature.

| Feature | Purpose | First-release plan | Notes |
| --- | --- | --- | --- |
| Recurring VTODO | Task series | Yes — planned | Native recurring tasks and standalone interchange under ADR 0017; lifecycle/occurrence details pending; no task iTIP/mail or implicit busy blocking |
| Standalone VFREEBUSY import | Read free/busy files | No — deferred | Generated output and authorized iTIP exchanges remain planned under ADR 0017 |
