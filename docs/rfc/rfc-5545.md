# RFC 5545 — iCalendar

Source: [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545.html), especially sections 3.2–3.8 and 8.3. **Pure wire adaptation: partial**, including the [standalone VEVENT/VTIMEZONE profile](../icalendar-event-adapter.md) and [recurring-master extension](../icalendar-recurring-masters.md), plus scoped [VFREEBUSY output](../freebusy-export.md). Component/property rows below describe the complete first-release plan, not blanket implementation or client compatibility. The pure temporal core, [native event CRUD](../native-single-events.md) and [recurrence storage/previews](../native-event-recurrence.md) are scoped implementations, not ICS support. First-release plans below follow existing requirements and proposed ADRs; they are not accepted conformance claims. See the [status legend](README.md) and [native/feed boundary](../compatibility.md).

Native status under [ADR 0056](../adr/0056-first-calendar-free-busy.md): per-calendar booking/fallback queries return merged privacy-safe UTC periods and complete/unknown coverage. Later ADRs 0057/0058 add native rules/search; ADR 0077 adds scoped authenticated VFREEBUSY output. Scheduling remains separate.

## Recurrence and temporal forms

**Current native profile:** [ADR 0041](../adr/0041-whole-second-1970-2100-profile.md) selects whole-second timing and ordinary dates in [1970-01-01, 2100-01-01), with explicit exclusive endpoints and generated future timezone coverage. It supersedes older precision/range notes. Fractional ICS timestamp/duration syntax remains invalid, including all-zero fractional timestamp suffixes; another supported input format may accept a mathematically whole-second spelling. Native validation is not an implemented parser/import/export claim.


[ADR 0029](../adr/0029-date-recurrence-rule-values.md) implements native DATE-only parameter range/combination validation and maintainer-confirmed sorted, duplicate-free native filter lists. [ADR 0030](../adr/0030-bounded-date-recurrence-generation.md) adds an initial bounded DATE-only generator with explicit mismatch/limit errors; [ADR 0031](../adr/0031-date-recurrence-week-numbers.md) adds native DATE-only yearly BYWEEKNO with all WKST values and scoped week-year evidence. [ADR 0033](../adr/0033-date-recurrence-sets.md) adds bounded native DATE-only union/subtraction. [ADR 0036](../adr/0036-date-event-series-overlap.md) adds scoped native uniform-length DATE-only span overlap queries, separate from wire support. [ADR 0037](../adr/0037-date-only-single-occurrence-exceptions.md) adds native single-occurrence DATE exceptions with bounded effective-set target validation and moved/changed-length overlap queries. [ADR 0038](../adr/0038-date-only-this-and-future-timing.md) adds scoped native DATE-only THISANDFUTURE timing and bounded overlap queries. [ADR 0040](../adr/0040-bounded-temporal-core-completion.md) adds selected native UTC/zoned recurrence, PERIOD sets, event timing edits, task milestone projections and bounded zone-offset comparison. Range cancellation, task edit/lifecycle reconciliation and wire parsing/export remain pending; table statuses describe end-to-end/native-and-interchange release scope rather than claiming it from core tests. Native ISO display fields under [ADR 0034](../adr/0034-native-iso-week-fields.md) are separate from rule-specific WKST membership and do not add a protocol feature.

## Current-state event export, 2026-10-23

[ADR 0082](../adr/0082-authenticated-current-event-export.md) and [the export guide](../event-export.md) implement explicit revision-bound complete series from one calendar. Require separate export permission and all supported read-disclosure groups, with complete selection context and repeated post-serialization checks.
