# RFC 9253 — iCalendar relationships

Source: [RFC 9253](https://datatracker.ietf.org/doc/html/rfc9253), sections 2–9. **Implemented today: No, for every row.** [Status legend](README.md). All listed rows have selected first-release scope; XML-REFERENCE is deferred and the rest use the documented native/interchange profile, with detailed constraints and implementation pending. Basic RFC 5545 RELATED-TO PARENT/CHILD/SIBLING support was confirmed in ADR 0010; the selected extensions here follow ADR 0014.

Native task/event linkage and availability associations can exist without claiming the complete RFC relationship model. Before implementation, define dangling references, cycles, tenant isolation, editing and feed UID transformation explicitly. Unsupported input remains rejected; automatic fetching or dependency execution is not authorized. See [ADR 0014](../adr/0014-rfc-extension-decisions.md), [ADR 0008](../adr/0008-module-clients-tasks-and-search.md) and [profile contracts](../roadmap.md#design-contracts).

## Decision records

Selected relationship metadata follows [ADR 0014](../adr/0014-rfc-extension-decisions.md). UID LINK targets remain collection-scoped; cross-collection links use authorized URI targets. Relationship/dependency metadata never executes workflows or changes dates, task state or bookings automatically. Exact graph, missing-target and projection constraints remain implementation work.

## Basic task source-reference boundary

[ADR 0093](../adr/0093-vtodo-source-references.md) implements only the pre-existing RFC 5545 basic task UID relationship wire slice. Missing/self/cyclic references remain unresolved source data with no native graph or workflow. None of this table's RFC 9253 extension rows is implemented by that increment; their validation/authorization/publication work remains required.

Basic RFC 5545 source UID relationships now persist and round-trip for VEVENT/VTODO under [ADR 0109](../adr/0109-inert-event-source-references.md)/ADR 0093. They are unresolved data and do not implement the RFC 9253 rows above, native graph traversal or dependency execution.
