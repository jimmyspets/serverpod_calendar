# RFC 7986 — Calendar property extensions

Source: [RFC 7986](https://www.rfc-editor.org/rfc/rfc7986.html), sections 4–6. **Scoped wire output:** ADR 0116 now adds optional event-feed presentation output as described below; source-envelope parsing and external-client interoperability remain separate. Scoped native decoded NAME/DESCRIPTION/COLOR editing/storage is now implemented under [ADR 0050](../adr/0050-calendar-presentation-and-protocol-text.md); Native URL/categories/image/refresh metadata and authorized category search are also implemented under [ADR 0051](../adr/0051-calendar-links-categories-images-refresh.md). The earlier native increments alone did not establish wire support. The optional feed increment now serializes only its explicit bounded presentation profile. [Status legend](README.md). Calendar descriptions are first-release scope; UID, LAST-MODIFIED and COLOR join the planned baseline; all listed rows now have a selected first-release profile; detailed contexts/limits and implementation remain pending.

General metadata support does not require all feed clients to render every field. Aggregate feeds have their own name/identity and description; multiple URLs for one feed share metadata. Module/interchange support remains independent of the narrower feed profile. All listed fields have selected scope; constraints for the remaining envelope/conference/extension profiles still need specification before accepting their input. The scoped native/feed profiles are documented separately. See [ADR 0014](../adr/0014-rfc-extension-decisions.md), FR-24 and [metadata work](../roadmap.md#icalendar-and-metadata).

## Decision records

Selected descriptive metadata follows ADRs [RFC scope](README.md) and [0014](../adr/0014-rfc-extension-decisions.md). Calendar images remain URI-only; imported SOURCE is private and excluded from subscriptions. Detailed constraints and per-surface projections still need implementation review.

## Optional feed output, 2026-10-25

[ADR 0116](../adr/0116-optional-event-subscription-contract.md) and [the guide](../http-event-feeds.md) bound feed metadata to explicit NAME/DESCRIPTION variants, COLOR, UID/LAST-MODIFIED, URL, native category groups, URI IMAGE/DISPLAY and whole-second REFRESH-INTERVAL. SOURCE and all alarms are excluded. This is serialization of the declared native editing profile, not general calendar-envelope import or client rendering compatibility. Batch validation is in progress.
