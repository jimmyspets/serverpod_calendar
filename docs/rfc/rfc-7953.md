## Shared RFC 5545 principles

The maintainer requested reuse of the selected RFC 5545 principles; see [ADR 0012](../adr/0012-calendar-availability-policy.md). Metadata choices now apply in legal availability contexts. Preserve host authorization, disclosure, no-fetch metadata, import-only CONTACT, bounded recurrence and atomic/no-loss handling. Approved ALTREP/LANGUAGE and organizer CN/DIR parameter policies follow the shared profile only where legal. DATE/floating starts and ends, event/task-only properties and nested alarms are not enabled. The maintainer subsequently selected per-calendar fallback (default free), separate calendar results and authenticated-only raw rules under [ADR 0012](../adr/0012-calendar-availability-policy.md). Optional person/resource summaries with host-selected contributing calendars and combined blocking bookings are confirmed; summary free time intersects independently evaluated contributors, including each calendar's rules, fallback and bookings. Detailed schema, numeric limits and zone/DST implementation remain under review. No wire interoperability or complete RFC property implementation is claimed.

## Implemented native subset

[ADR 0057](../adr/0057-native-working-hours.md) implements optional validity bounds, explicit UTC/named-zone opening timing, stable generated native/protocol identities, native whole-second modification time, priority 0–9, BUSY/UNAVAILABLE/TENTATIVE closed types, optional summary, selected RRULE/RDATE/EXDATE recurrence, authenticated management and bounded complete-or-unknown calculation with bookings. Fallback applies only outside effective definitions. Shared temporal guards/WKST/DST remain authoritative. Native envelope DURATION shorthand, opening RECURRENCE-ID overrides, rich metadata, wire timestamps/properties and import/export remain pending; shared opening DURATION timing is implemented. Raw rules are not published through bearer feeds. This does not implement CalDAV or VAVAILABILITY scheduling messages.

[ADR 0058](../adr/0058-subject-availability-search.md) implements scoped native person/resource summaries and per-target/common-free search, intersecting independently evaluated complete contributor calendars. This adds no RFC wire properties, VFREEBUSY serialization, CalDAV or scheduling transport. Cross-scope aggregation and group expansion remain separate designs.
