# RFC 6868: Parameter value encoding

Source: [RFC 6868](https://www.rfc-editor.org/rfc/rfc6868.html). This updates RFC 5545 parameter encoding, not calendar property/component semantics.

| Feature | Native syntax foundation | Boundary |
| --- | --- | --- |
| Caret, newline and quote encoding | Implemented in explicit parameter codecs and syntax serializer | Separate from backslash TEXT escaping; decoded newline is LF |
| Parameter decoding in quoted/unquoted values | Implemented | Quoting/delimiters follow general content-line grammar; applicability/cardinality remains per-property semantic validation |
| Unknown caret sequences | Preserved literally | No silent repair or discard |
| Component/property support | Not implied | Syntax retention is not supported-profile acceptance, domain import or publication authority |

[ADR 0062](../adr/0062-bounded-icalendar-syntax-foundations.md), [the syntax guide](../icalendar-syntax.md) and [validation evidence](../scaffold-validation.md) define the bounded native adapter foundation. No vCard/XML/JSON format adapter, complete iCalendar interchange or external-client compatibility is claimed.
