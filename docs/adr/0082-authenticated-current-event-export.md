# ADR 0082: Authenticated current-state event export implementation

Status: **scoped ADR 0081 implementation; maintainer-confirmed rejection of unrepresentable cancellation restoration state; concrete mechanics under draft review**. Date: 2026-10-23.

Implement explicit revision-bound complete event series selected from one calendar. Require independent parent/member exportEvents permission plus readEvent with every supported event field group. Supply actual parent and a frozen full current selection to the host; authorize before concurrency/output checks and repeat current-context/full-source checks after serialization. Any missing, foreign, stale, denied, withheld, unsupported or over-limit member rejects the whole file. No partial/redacted file, source UID renaming or silent truncation.

Build current content, recurrence/PERIODs, exact single/THISANDFUTURE identities, text annotations, source property presence and independent checkpoints. Exclude historical import baseline, native IDs and database audit presentation. Regenerate standalone envelope and pinned full-horizon VTIMEZONE definitions. Validate output against the existing pure wire profile, decode it to the normalized native representation and compare complete current semantics. This uses a temporary current-state canonical value, never the stored historical baseline. Reject a mismatch rather than flattening behavior.

The maintainer explicitly selected rejection of native cancellation-only exceptions without a replacement span: inventing an emitted DTSTART/span would change restoration inheritance after reimport. Also reject any status/presence projection that changes independent cancellation behavior, missing checkpoints, duplicate source UIDs and aggregate unsupported raw components. Explicit source cancellation spans remain exportable when their complete state round-trips. Native capability is retained even when this initial interchange profile cannot represent it.

Use immutable calendar/event revision selections, at most 128 raw VEVENT components including overrides and existing syntax/temporal/zone/recurrence budgets. Sort service output by exact protocol UID and zone identifiers for deterministic bytes. Reads change no revision, protocol/audit time, baseline or scope generation. No event replacement, HTTP feed, scheduling/mail or alarm activation follows. No new storage/migration is required.

Validate independent permissions and every field group, source-preserving/current-state output, deterministic bytes, post-serialization revocation/outage/context, stale/wrong-parent/missing/deleted selections, raw limits, nonrepresentable state and unchanged storage. Exercise two independent hosts, generated clients and Flutter output separately from external-client compatibility. Preserve the whole-second [1970,2100) profile and pinned timezone update procedure.
